# ADR-0002: Главная — статичный лендинг, страница записи — заглушка

В первой итерации главная страница — статичный лендинг без обращения к бэкенду: она только рассказывает о сервисе и ведёт на страницу записи. Страница записи — маршрут-заглушка без формы выбора слота.

Бэкенд в этой итерации не задействуется: бэкенд-эндпоинтов приложения ещё нет, а раздувать фичу выбором данных не требуется. Страница записи и интерфейс владельца календаря — отдельные фичи со своей логикой. Главная страница намеренно остаётся читаемой без данных и не падает, когда бэкенд недоступен.
