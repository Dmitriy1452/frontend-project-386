# ADR-0001: Клиентская навигация на React Router

Приложение имеет несколько страниц, адресуемых по URL: `/` — главная страница, `/booking` — страница записи. Навигация реализована через `react-router-dom` (`BrowserRouter` + `Routes`), компоненты страниц лежат в `frontend/src/pages/`.

Выбрали React Router вместо переключения по стейту React: URL-адресуемость даёт шаринг ссылок на страницы (например, ссылку на запись), предсказуемую структуру при росте числа страниц и соответствие стандарту экосистемы React. Переключение по стейту отвергнуто — оно ломает шаринг ссылок и требует переделки при появлении новых страниц.
